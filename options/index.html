Host Jumper

Save relative paths, then press Ctrl+Shift+F to jump to them on the current site. Placeholders such as {id} or {id,object} are filled from the current page URL.

Add a path

Examples: /test, /cart, /user?id={id,object}. Query parameters, hash parameters, and path segments ({1}, {2}, …) can be used as placeholders. A list like {id,object} uses the first matching value.
